## Manuscript settings represented in the code

- Uniform linear array with `M=10` and half-wavelength inter-element spacing.
- Two sources for the main learned model and performance experiments.
- Training DOA grid from `-60` to `60` degrees with `0.5` degree spacing.
- Training SNR sampled from `-20` to `5` dB.
- Proposed-method training set containing 202,440 population covariances from all unordered two-source grid pairs with seven realizations per pair.
- Twenty percent correlated-source training examples with correlation below full coherence.
- `90%/10%` training/validation split.
- Random seed 42 for the main proposed-method training procedure.
- PoR tolerance of one degree in the manuscript performance experiments.

Individual scripts remain the authoritative record for experiment-specific settings.
