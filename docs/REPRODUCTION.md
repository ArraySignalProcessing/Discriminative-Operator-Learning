# Reproduction workflow

All data are generated by repository code. Run MATLAB scripts from MATLAB after changing the current folder to the repository root or adding the repository MATLAB directory to the path. Run Python scripts from their respective source directories unless explicit paths are supplied.

## 1. Train the proposed method

```bash
cd python_Ours
python Ours_Generate_allpairs.py --out Ours_train.h5
python Ours_train.py --data Ours_train.h5 --output ours_model.pth
```

The all-pairs generator enumerates unordered two-source combinations on the training grid and creates seven realizations per pair, yielding 202,440 examples under the manuscript settings.

## 2. Train MLC

```bash
cd python_CNN
python CNN_Generate_allpairs.py --out CNN_train.h5
python CNN_train.py --data CNN_train.h5 --output cnn_model.pth
```

The implementation directory retains the historical name `python_CNN`; the manuscript calls this baseline MLC.

## 3. Train SubspaceNet

```bash
cd python_SubspaceNet
python SubspaceNet_Generate_train.py --out Subspace_train_rho.h5
python train_SubspaceNet.py --data Subspace_train_rho.h5 --output subspace_model.pth
```

## 7. B4 ablation

Generate the common evaluation data:

```matlab
run('matlab/generateB4_operator_ablation.m')
```

From `python_Ours`, train the three models with the same training data and default manuscript settings:

```bash
cd python_Ours
python trainB4_operator_ablation.py --loss_mode projector_fitting --data Ours_train.h5
python trainB4_operator_ablation.py --loss_mode null_only --data Ours_train.h5
python trainB4_operator_ablation.py --loss_mode full --data Ours_train.h5
```

The commands write `ablation_models/B4_projector_fitting.pth`, `ablation_models/B4_null_only.pth`, and `ablation_models/B4_full.pth`. Export learned operators for both source-count cases generated by MATLAB:

```bash
python expB4_operator_ablation_export_Q.py \
  --data ../data/B4/B4_OperatorAblation_QPn_K1.h5 \
  --out ../data/B4/B4_Ablation_Q_K1.h5

python expB4_operator_ablation_export_Q.py \
  --data ../data/B4/B4_OperatorAblation_QPn_K2.h5 \
  --out ../data/B4/B4_Ablation_Q_K2.h5
```

Finally, return to the repository root and run:

```matlab
run('matlab/plotB4_operator_ablation.m')
```

## Expected variability

The scripts set random seeds, but exact floating-point results can still vary with CPU/GPU hardware, CUDA kernels, PyTorch versions, MATLAB releases, and eigendecomposition/root ordering. Reproduction should compare the reported trends and use reasonable numerical tolerances rather than requiring byte-identical result files.
