# Task-Driven Learning of DOA-Discrimination Operators for MUSIC-Type DOA Estimation

This repository contains the source code accompanying the manuscript **“Task-Driven Learning of DOA-Discrimination Operators for MUSIC-Type DOA Estimation.”** It implements a task-driven neural mapping from covariance matrices to DOA-discrimination operators and constructs MUSIC-type spatial spectra from the learned operators.

All training data, test observations, intermediate numerical results, and figures are generated by the included Python and MATLAB programs. No external experimental dataset is required. Generated datasets, trained checkpoints, numerical results, figures, and manuscript files are intentionally excluded from version control.

## Repository structure

```text
proposed_method/        Proposed method: data generation, training, inference, and ablation
baseline_mlc/           Grid-based multi-label classification (MLC) baseline
baseline_subspacenet/   SubspaceNet baseline
matlab/                 Simulation generation, classical baselines, and plotting
matlab/function/        Shared MATLAB functions
data/                   Generated experiment data and results (not tracked)
figures/                Generated paper figures (not tracked)
```

The source filenames are retained from the working experimental codebase to preserve the tested execution flow. In particular, files beginning with `CNN_` implement the MLC baseline, while files beginning with `Ours_` implement the proposed method.

## Relationship to the manuscript

The current manuscript uses six experiment groups:

- **B1:** noise-subspace projector deviation under finite snapshots and low SNR;
- **B2:** spectral-gap narrowing and projector deviation under source correlation;
- **B3:** spatial-response comparison between the sample noise-subspace projector and the learned operator;
- **B4:** ablation of the operator-construction criteria;
- **C1:** resolution of closely spaced sources;
- **C2:** resolution under correlated and fully coherent sources.

The repository also retains supplementary investigations that are not used for the main figures or quantitative claims of the current manuscript:

- **B5:** consistency between grid and Root-MUSIC-type inference backends;
- **B6:** exploratory source-count experiments for `K=1,2,3`;
- **C3:** array-model mismatch;
- **C4:** SNR sweep;
- **C5:** snapshot-count sweep;
- **Root-Ours:** an alternative Root-MUSIC-type backend for the learned operator.

## Environment

Recommended environment:

- Python 3.10 or 3.11;
- PyTorch 2.x;
- NumPy;
- h5py;
- matplotlib;
- tqdm;
- MATLAB with the Phased Array System Toolbox and Signal Processing Toolbox.

CUDA is optional. The Python scripts use CUDA when available and otherwise run on CPU. Full training and Monte Carlo evaluation can be substantially slower on CPU.

Using Conda:

```bash
conda env create -f environment.yml
conda activate discriminative-operator-learning
```

Alternatively, using `venv`:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Before running MATLAB experiments, start MATLAB in the repository root and add the MATLAB source tree to the path:

```matlab
addpath(genpath('matlab'));
```

## Training

The proposed method and MLC are trained from population covariance matrices. SubspaceNet is trained from finite-snapshot correlation features.

### Proposed method

```bash
cd proposed_method
python Ours_Generate_allpairs.py --out Ours_train.h5
python Ours_train.py --data Ours_train.h5 --output ours_model.pth
cd ..
```

The default all-pairs generator enumerates all unordered two-source combinations on the `[-60°, 60°]` grid with `0.5°` spacing and generates seven nonideal realizations per pair, yielding 202,440 training examples.

### MLC baseline

```bash
cd baseline_mlc
python CNN_Generate_allpairs.py --out CNN_train.h5
python CNN_train.py --data CNN_train.h5 --output cnn_model.pth
cd ..
```

### SubspaceNet baseline

```bash
cd baseline_subspacenet
python SubspaceNet_Generate_train.py --out Subspace_train_rho.h5
python train_SubspaceNet.py --data Subspace_train_rho.h5 --output subspace_model.pth
cd ..
```

- B6: the `K3` generation/training scripts in `proposed_method/`, `matlab/generateB6_k123_composite_spectrum_data.m`, `proposed_method/expB6_k123_composite_spectrum_export_Q.py`, and the B6 MATLAB plotting scripts;

- Root-Ours: `proposed_method/testC*_root.py`.

B6 remains exploratory: the retained scripts support multiple K=3 training variants, so any reported B6 result should identify the exact training command and checkpoint used.

## Reproducibility notes

- Training and test data are generated independently.
- Training DOAs lie on the fixed grid; C1 and C2 use off-grid test DOAs.
- Random seeds are set in the individual scripts.
- At least 1,000 Monte Carlo trials are used per operating point in the manuscript performance experiments.
- The PoR angular-error tolerance is `1°`.
- Exact floating-point results can vary across hardware, MATLAB releases, PyTorch versions, CUDA kernels, and eigendecomposition/root ordering.
- The current model is configured for a ten-element half-wavelength ULA. A different array geometry requires corresponding model and data-generation changes.

## Third-party software and baseline attribution

Python dependencies are installed from their normal package channels and are not vendored. MATLAB is required for simulation generation, classical baselines, and plotting.

CVX is required only when the optional l1-SVD branches are enabled. CVX and its solver binaries are not included; users must install [CVX](https://cvxr.com/cvx/) separately and comply with its licensing terms.

The MLC baseline follows:

> G. K. Papageorgiou, M. Sellathurai, and Y. C. Eldar, “Deep Networks for Direction-of-Arrival Estimation in Low SNR,” *IEEE Transactions on Signal Processing*, vol. 69, pp. 3714–3729, 2021, doi: [10.1109/TSP.2021.3089927](https://doi.org/10.1109/TSP.2021.3089927).

The DeepCNN implementation in the [official SubspaceNet repository](https://github.com/ShlezingerLab/SubspaceNet) was used as an architectural reference. The local implementation uses this project’s covariance format, grid, data generator, training loop, and evaluation interface.

The SubspaceNet baseline follows:

> D. H. Shmuel, J. P. Merkofer, G. Revach, R. J. G. van Sloun, and N. Shlezinger, “SubspaceNet: Deep Learning-Aided Subspace Methods for DoA Estimation,” *IEEE Transactions on Vehicular Technology*, vol. 74, no. 3, pp. 4962–4976, 2025, doi: [10.1109/TVT.2024.3496119](https://doi.org/10.1109/TVT.2024.3496119).

Its convolution/deconvolution architecture and differentiable Root-MUSIC flow follow the corresponding [official implementation](https://github.com/ShlezingerLab/SubspaceNet). The local implementation adapts the method to this project’s data format, array convention, training settings, checkpoint format, and evaluation scripts.
